Escríbenos desde aquí

Esta versión está pensada para GitHub Pages. El formulario abre tu aplicación de correo con el mensaje listo, así el sitio sigue siendo liviano y no depende todavía de un servicio externo.

Enviar mensaje

Completa los campos y el botón preparará el correo automáticamente. El texto saldrá con asunto y cuerpo ya organizados para que el contacto sea más claro.

Este formulario no guarda datos en la página. Solo organiza el contenido y abre el correo desde el dispositivo del visitante.

Antes de publicar

Dejé esta página lista para que funcione bien visualmente desde ya, pero con una configuración sencilla. Solo necesitas poner tu correo real en una sola línea del script.

Cambio obligatorio Reemplaza el correo de ejemplo por tu correo real en la constante CONTACT_EMAIL.
Cómo funciona Los botones de correo y el formulario usarán automáticamente esa dirección.
Más adelante Cuando quieras un formulario que sí envíe sin abrir el correo, ahí se integra un servicio externo.
